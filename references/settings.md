# settings.json 字段说明

工程的 `src/settings.json` 保存视频的全部可调内容。字段名是中文的，控制台和视频代码都直接用这些名字。完整的类型定义在 `src/AppPreview.tsx` 开头的 `schema`，以它为准。

图片类字段的填法：留空 = 显示占位；填 `public/` 下的文件名（如 `nav.png`、`uploads/123.png`）；或者填 http 链接。功能页的 `截图` 还可以填 `.mp4` / `.mov` 录屏。

## 顶层

| 字段 | 内容 |
|---|---|
| `品牌` | `标语`（结尾 Logo 下面的一句话）、`主色`、`深色`、`背景色`（十六进制颜色）、`图标`（开场用的 App 图标）、`字标`（结尾用的带文字 Logo） |
| `开场` | `图标大小`（120–500）、`时长`（秒）、`图标动画`：旋转弹出 / 从上落下 / 放大淡入 / 翻转 |
| `页面` | 数组，按播放顺序排列。每一项是功能页或卡片页，见下 |
| `结尾` | `字标宽度`（300–820）、`时长`、`转场`、`标志动画`：弹出 / 放大淡入 / 从下升起 |
| `样式` | `标题字号`（50–130）、`手机宽度`（420–760）、`弹跳感`（0 平稳 – 10 很弹）、`逐词间隔`、`音效音量`（0–1，0 是静音） |

总时长 = 开场 + 各页面 + 结尾的 `时长` 之和，30 帧 = 1 秒。

## 功能页（`类型: "功能页"`）

| 字段 | 内容 |
|---|---|
| `名称` | 只显示在控制台页签上，不出现在视频里 |
| `第一行` / `第二行` | 两行大字 |
| `截图` | 手机里的画面：截图或录屏 |
| `示意` | 没放截图时播放哪个示意动画，默认 `"无"`（模板里没有登记任何示意动画） |
| `高亮` | 讲解区域数组，每项 `{文字, 左, 上, 宽, 高}`，位置和大小是占截图的百分比（0–100）。建议 2–3 个 |
| `时长` | 秒（1–8）。有讲解区域时：约 1.2 秒 + 每个区域（`讲解停留` + 0.3 秒） |
| `转场` | 这一页盖住上一页的方式：上推 / 左推 / 右推 / 圆形扩散 / 三角推进 / 向下擦除 / 缩放 / 淡入 / 直接切换 |
| `配色` | 蓝底（主色）/ 白底（背景色）/ 深色底（深色） |
| `标题动画` | 弹出 / 上滑 / 淡入 / 打字 / 逐字弹出 |
| `手机进场` | 从下升起 / 从左滑入 / 从右滑入 / 放大出现 / 倾斜转正 / 直接出现 |
| `手机动态` | 进场后的持续动态：缓慢放大 / 上下漂浮 / 轻微摆动 / 静止 |
| `讲解效果` | 放大弹出（区域抠出来浮在手机上）/ 镜头推近（整个屏幕朝区域放大）/ 描边闪烁（原位置发光的框） |
| `显示手指` / `压暗背景` | 布尔。讲解时是否显示手指点击、是否压暗其余部分 |
| `讲解停留` | 每个讲解区域停留几秒（0.6–2.5） |
| `小车` | `{开启, 左, 上, 宽, 高, 距离, 方式, 变灰轨迹}`。把截图里的车辆图标抠出来沿直线路线往前开，给导航类截图用。`左/上/宽/高` 是车辆在截图上的位置（百分比），`距离` 是往前开多远（占屏幕高度 5–40），`方式`：匀速 / 缓起缓停 / 走走停停 |
| `提示` | `{开启, 红色文字, 绿色文字}`。在手机画面上先弹出一条红色提示，再换成绿色提示，例如"No signal"→"Offline map" |

## 卡片页（`类型: "卡片页"`）

| 字段 | 内容 |
|---|---|
| `名称`、`第一行`、`第二行`、`时长`、`转场`、`配色`、`标题动画` | 同功能页 |
| `卡片动画` | 两侧飞入 / 原地弹出 / 从上落下 / 翻牌 |
| `卡片` | 数组，每项 `{文字, 图片, 色相}`。没有图片时显示渐变色块加文字，`色相` 是 0–360。最多放 6 张 |

## 新增页面的完整示例

新增一页时字段要写全，缺字段会在渲染时报错。最稳妥的做法是复制已有的一页再改，或者参考 `src/AppPreview.tsx` 里的 `newFeaturePage()` / `newCardPage()`。
